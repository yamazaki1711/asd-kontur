# АСД-КОНТУР

**АСД-КОНТУР** — цифровой комплекс анализа и управления доказательствами строительного процесса.

Система охватывает четыре режима жизненного цикла объекта капитального строительства:

1. **ТЕНДЕР** — оценка обязательств, стоимости и рисков до заключения договора.
2. **СОПРОВОЖДЕНИЕ** — накопление доказательств одновременно с выполнением СМР.
3. **АУДИТ** — сопоставление обязательного и фактически имеющегося комплекта доказательств.
4. **ВОССТАНОВЛЕНИЕ** — допустимое устранение подтвержденной доказательной дельты.

## Единое доменное ядро

> ПД/РД + договорные требования + регламент заказчика + НТД → структура ОКС → виды и объёмы работ → МТР → контрольные операции → обязательные доказательства → ИД → предъявление объёмов → КС → оплата.

## Текущий этап

Проектирование. Первый промышленный MVP — режим **«СОПРОВОЖДЕНИЕ»** на одном пилотном фрагменте реального ОКС.

На этом этапе репозиторий содержит проектные решения и функциональную документацию. Программная реализация начинается только после утверждения функциональной модели MVP и технической архитектуры.

## Структура

- `docs/product/` — назначение, границы и продуктовая модель;
- `docs/mvp/` — функциональная модель и критерии приемки MVP;
- `docs/architecture/` — техническая архитектура;
- `docs/architecture/decisions/` — журнал архитектурных решений (ADR).

## Статус решений

- новое детерминированное ядро проектируется отдельно от MAC_ASD v16.1;
- MAC_ASD v16.1 используется только как источник компонентов после аудита;
- первый MVP — «СОПРОВОЖДЕНИЕ»;
- юридически значимый ЭДО не входит в первый MVP;
- полевой клиент проектируется offline-first;
- любой машинный вывод должен быть трассируем до версии и фрагмента источника;
- репозиторий должен оставаться приватным до отдельного решения владельца проекта.
