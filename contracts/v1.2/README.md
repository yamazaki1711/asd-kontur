# ASD-KONTUR Tender Contract Extension v1.2

Status: **Accepted WP-12 implementation contract extension**

Owner: Oleg Shcherbakov

Date: 2026-08-23

This immutable additive release preserves Contract Pack v0.1 and extensions
v1.0/v1.1. It gives the WP-12 boundary typed clause findings, five distinct
Tender deliverables, and terminal process events. References resolve only from
the checked-in local contract bundle; network schema resolution is forbidden.

The schema deliberately does not encode legal applicability as model output.
Every material finding pins a source clause, evidence, a `RuleSetVersion`, and a
`RuleTrace`; finalization pins two distinct qualified human decisions. A
rendered file is outside this contract and is not implicitly print-ready.
