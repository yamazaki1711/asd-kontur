# Contract Pack v2.6

Additive product-acceptance contract for `PILOT-USABLE-END-TO-END-01`.
It preserves the 143-capability denominator and Contract Pack v2.5 intake
decisions.  The pack defines the bounded pilot corpus, four professional
outputs, export denominator, measurable operating thresholds and the exact
criteria for an append-only runtime `TrialReadinessDecision`.

The fixture intentionally records `pending_external_acceptance`: Trial
readiness is not predetermined in Git.  The authoritative decision is created
only after external browser acceptance against the exact deployed commit,
restart/isolation checks and a recorded rollback target.
