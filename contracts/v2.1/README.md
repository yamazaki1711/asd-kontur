# Contract Pack v2.1 — Product Application Spine

Additive contracts for the first production-shaped browser/application boundary. The pack preserves
all earlier Contract Pack versions and does not change canonical Practice/NTD memory.

The OpenAPI artifact is deterministic build output. `spine-contract-fixture.schema.json` validates
the cross-resource fixture and fail-closes readiness: the visible Spine does not imply Trial, OKS,
Mode, or Product readiness. The fixture also carries an explicit readiness delta against the complete
v2.0 Capability Registry and measured-only 1k/5k/10k scale outcomes. An unset numerical acceptance
threshold keeps all three scale capabilities at `PARTIAL`.
