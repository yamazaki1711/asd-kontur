# ASD-KONTUR Contract Pack v1.3

Immutable additive WP-13 extension for Support process events, evidence-bound
generation outcomes, semantic executive schemes and commercial readiness.

It preserves `v0.1`, `v1.0`, `v1.1` and `v1.2`. The extension does not define a
transport protocol and does not qualify an official template or production
renderer. `synthetic_semantic_final` is explicitly distinct from production
`print_ready`.

All `$ref` values resolve through the local Contract Pack store. Network schema
resolution and mutable `latest` references remain forbidden.
