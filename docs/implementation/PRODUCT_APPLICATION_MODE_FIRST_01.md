# PRODUCT-APPLICATION-MODE-FIRST-01

## Что теперь умеет АСД-КОНТУР как продукт

После входа пользователь сначала выбирает профессиональную задачу: тендерный анализ, инженерное сопровождение, аудит или восстановление. Затем он выбирает доступный объект капитального строительства либо создаёт новый объект без ввода технических идентификаторов. Один объект открывается во всех четырёх режимах; режим является контекстом текущей работы и сохраняется в адресе страницы.

Внутри объекта шапка показывает его название и текущий режим. Пользователь может явно сменить объект или режим. Для каждого режима начальная страница объясняет назначение, доступные исходные данные, ожидаемые профессиональные результаты, незавершённые вопросы и следующее действие. Существующие документы, обработка, исходные сведения, матрица работ, точные исходные фрагменты и комплект исполнительной документации остаются доступны из русскоязычного меню.

## Пользовательский маршрут

Канонический маршрут:

`вход → /modes → /modes/{mode}/workspaces → /modes/{mode}/workspaces/{workspace}`

Поддержаны четыре контекста:

- `tender` — «Тендерный анализ»;
- `support` — «Инженерное сопровождение»;
- `audit` — «Аудит»;
- `restoration` — «Восстановление».

Выбранный режим не записывается как неизменяемое свойство ОКС. Это воспроизводимый URL-контекст поверх общей изолированной памяти объекта. Обновление страницы, переходы назад/вперёд и прямая ссылка сохраняют контекст. Старые ссылки `/workspaces/{id}/…` не выбирают режим автоматически: пользователь получает экран явного выбора, после чего исходный раздел открывается в выбранном режиме.

## Выбор и создание ОКС

Страница режима показывает только активные объекты, доступные текущему владельцу сессии. Последний открытый объект запоминается отдельно для каждого режима в браузерном пользовательском предпочтении; это не меняет канонические данные ОКС.

Создание использует действующую команду Application API `POST /api/v1/workspaces` и требует только профессионально понятное название объекта. Organization, workspace и construction-object identities формируются существующим application boundary. После успешной команды объект сразу открывается в выбранном режиме.

Демонстрационный workspace отображается как «Демонстрационный объект» без изменения его канонической identity или накопленного package/finalization state.

## Пользовательская и административная поверхности

Из основной навигации убраны технические названия инфраструктуры, capability codes, UUID объектов и англоязычные имена режимов. Вход оформлен как «АСД-КОНТУР / Вход в комплекс». Состояния обработки, комплектности и документов получают русские пользовательские наименования; неизвестный внутренний blocker не показывается пользователю как код.

Системное состояние и нормативная база сохранены, но вынесены из рабочего меню:

- `/admin/system` — состояние развернутого комплекса;
- `/admin/knowledge` — нормативная база и методики;
- `/admin/workspaces/{id}/reset` — контролируемый административный reset.

На административных страницах сначала показывается русское объяснение. Commit, migration head, digests, denominators и внутренние состояния находятся в закрытом по умолчанию блоке «Технические сведения».

## Визуальная система и адаптивность

Существующий React frontend сохранён. Его оболочка приведена к визуальному языку публичного сайта: тёмно-зелёная основа, тёплый светлый фон, золотой акцент, спокойная типографика и умеренные скругления. Экран режимов имеет сетку 2×2 на desktop и одну колонку на mobile. Для таблиц сохранена локальная прокрутка; страница целиком не получает горизонтальный overflow.

Автоматический браузерный контракт проверяет размеры 1440×900, 1280×720, 390×844 и 360×800 с инвариантом `documentElement.scrollWidth == documentElement.clientWidth`.

## Сохранённая продуктовая цепочка

Сохранены существующие API, RLS/workspace isolation, durable jobs/SSE, Document Registry, Project Understanding, WorkRequirementMatrix, Knowledge Gateway, четыре mode API, Support package lifecycle, четыре immutable PackageVersion/RegisterVersion, FinalizedDocument, PDF viewer и HTTP Range download.
