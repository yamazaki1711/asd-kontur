# ADR-0002: Первый MVP — «СОПРОВОЖДЕНИЕ»

- Статус: принято как рабочая проектная гипотеза
- Дата: 2026-08-11

## Контекст

Четыре режима используют единое доменное ядро. Наиболее качественные доказательства возникают непосредственно в процессе строительства, до сокрытия конструкций и утраты первичных данных.

## Решение

Первым промышленным MVP сделать режим «СОПРОВОЖДЕНИЕ» на ограниченном фрагменте одного реального ОКС.

## Последствия

- полевые данные становятся основой последующего аудита;
- объём MVP ограничивается сквозным, но узким производственным сценарием;
- режимы «ТЕНДЕР», «АУДИТ» и «ВОССТАНОВЛЕНИЕ» учитываются в доменной модели, но не реализуются полностью на первом этапе.
