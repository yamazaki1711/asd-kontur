# ADR-0002: Историческая гипотеза первого MVP «СОПРОВОЖДЕНИЕ»

- Статус: Superseded
- Дата: 2026-08-11
- Заменено: ADR-0007, принято владельцем продукта 2026-08-21

## Контекст

Четыре режима используют единое доменное ядро. Наиболее качественные доказательства возникают непосредственно в процессе строительства, до сокрытия конструкций и утраты первичных данных.

## Историческое решение

Использовать режим «СОПРОВОЖДЕНИЕ» на ограниченном фрагменте одного
реального ОКС как первый внутренний вертикальный срез разработки.

Эта формулировка больше не определяет границу MVP или промышленной
готовности продукта. Согласно ADR-0007 АСД-КОНТУР считается готовым только
при сквозной готовности всех четырёх режимов: `Tender`, `Support`, `Audit`,
`Restoration`.

## Последствия

- полевые данные становятся основой последующего аудита;
- внутренний Support-срез может использоваться для поэтапной разработки и
  проверки общего ядра;
- завершение этого среза не является готовностью АСД-КОНТУР;
- все четыре режима обязаны достичь критериев ADR-0007 до объявления
  промышленной готовности продукта.
