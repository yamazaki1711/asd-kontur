# ADR-0001: Новое ядро АСД-КОНТУР

- Статус: Accepted
- Дата: 2026-08-11
- Статус нормализован: 2026-08-22 ведущим архитектором Codex по явным
  архитектурным полномочиям владельца продукта; содержание решения не менялось

## Контекст

MAC_ASD v16.1 содержит значительный объём наработок, однако новая продуктовая модель требует единого доменного ядра, детерминированной системы правил, темпоральной применимости требований и полной трассируемости выводов.

## Решение

Проектировать АСД-КОНТУР в отдельном репозитории. Не переносить прежний код целиком. Каждый компонент MAC_ASD допускается к переносу только после отдельной проверки его назначения, качества, безопасности, тестируемости и соответствия новой модели.

## Последствия

- архитектура не наследует старые ограничения автоматически;
- полезные компоненты могут быть переиспользованы контролируемо;
- потребуется отдельная карта аудита и миграции компонентов;
- MAC_ASD сохраняется без разрушительных изменений как источник истории и наработок.
