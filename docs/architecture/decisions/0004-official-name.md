# ADR-0004: Официальное наименование комплекса

- Статус: принято
- Дата: 2026-08-11

## Контекст

В ранних материалах использовались обозначения «АСД», «АСД-Контур» и рабочее имя репозитория `asd-kontur`.

## Решение

Полное официальное наименование комплекса — **АСД-КОНТУР**.

Название репозитория и технический slug — `asd-kontur`.

## Последствия

- во всей новой проектной, пользовательской и эксплуатационной документации применяется «АСД-КОНТУР»;
- прежние обозначения сохраняются только в исторических документах и ссылках на них;
- имя репозитория, пакетов и URL не изменяется без отдельного решения.
