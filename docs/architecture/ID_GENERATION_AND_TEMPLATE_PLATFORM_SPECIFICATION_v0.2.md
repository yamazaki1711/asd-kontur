# ID Generation & Template Platform Specification v0.2

This additive product-surface amendment preserves v0.1. The existing template,
candidate, evidence and finalization contracts remain valid foundations; they
do not constitute a production generator.

The capability must be reachable through the typed Product Application,
consume exact ProjectDefinition/WorkPackage/Matrix and Gateway context, and
show field-level source, methodological advice, normative evidence, workspace
fact, uncertainty and blocker. Template assets require immutable edition,
authority/license provenance and qualification. DOCX/XLSX/PDF/DXF outputs
require layout/render and print acceptance appropriate to format.

The UI supports selecting work/document/form, reviewing source values and
missing inputs, previewing visual examples, generating a
`GeneratedDocumentCandidate`, resolving blockers, professional finalization
and reproducible export/archive. It cannot invent facts or promote Practice
Guidance/NTD to RuleVersion.

Legacy template assets and generation algorithms are candidates only under the
[Legacy Component Decision Gate](LEGACY_COMPONENT_DECISION_MATRIX_v1.md).
Current production rendering/print and user workflow status is
`NOT_IMPLEMENTED`/`CONTRACT_ONLY`; ProductReady remains false.
